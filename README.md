# Vesper Navigator Site

Vesper Navigator Site is the official landing and demo page for the Vesper Navigator Android browser.

## Purpose

- Present an overview of Vesper Navigator.
- Provide demo links and test actions for the Android app (navigation, JavaScript, and deep links).
- Serve as a simple, static reference page for development and QA.

## Development

1. Install dependencies:

```
    bash
      npm install   
```

2. Run the dev server:

```
   bash   
      npm run dev   
```

3. Build for production:
```
   bash   
      npm run build   
```
